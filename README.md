# TTW DualScreen

An xNVSE plugin plus Android companion app that turns the second screen of the AYN Thor into a live
companion display for Tale of Two Wastelands (Fallout: New Vegas).

Status: milestone 0 spike.

## Try the spike

Download the latest pre-release: https://github.com/TristanAdams03/ttw-dualscreen/releases
Then follow the [device checklist](docs/spike/CHECKLIST.md).

Design: [docs/superpowers/specs/2026-11-03-ttw-dualscreen-design.md](docs/superpowers/specs/2026-11-03-ttw-dualscreen-design.md)

Protocol: [protocol/PROTOCOL.md](protocol/PROTOCOL.md)

License: GPL-3.0-or-later. No Bethesda or TTW assets are included.

New to TTW on Android? Start with the [setup guide](docs/guide/ttw-on-ayn-thor.md). It covers building TTW on a PC, moving it to the Thor, and setting up GameNative.
